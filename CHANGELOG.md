# 📘 Changelog

Todas as alterações importantes deste projeto serão documentadas neste arquivo.  
O formato segue o padrão [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/)  
e o versionamento [SemVer](https://semver.org/lang/pt-BR/).

---

## [1.1.0] - 2025-10-30
### Adicionado
- Implementação completa de **acessibilidade** conforme **WCAG 2.1 Nível AA**.
- Suporte à **navegação por teclado** em todos os componentes interativos.
- Inclusão de **modo alto contraste** e **modo escuro** com alternância dinâmica.
- Adicionado script de **build automatizado** (`npm run build`) para minificação e compressão de arquivos.
- Inclusão de **README profissional** detalhando o projeto, tecnologias e instruções de execução.

### Alterado
- Atualização do CSS para **melhor visibilidade de foco** e contraste.
- Organização do repositório seguindo o **padrão GitFlow**.
- Ajustes de commits para seguir **convenções semânticas** (`feat`, `fix`, `chore`, `docs`).

### Corrigido
- Correções em validações de formulários e feedback visual ao usuário.
- Ajuste na exibição de alertas e foco após o envio de formulários.

---

## [1.0.0] - 2025-10-25
### Lançamento inicial
- Estrutura base da **SPA (Single Page Application)**.
- Criação dos **templates dinâmicos** via JavaScript.
- Sistema de **validação de formulários**.
- Integração inicial de **manipulação do DOM** e **rotas SPA**.
- Deploy inicial no GitHub Pages.
